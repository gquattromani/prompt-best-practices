# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Summary

- Be respectful, constructive, and inclusive in all interactions — issues, pull requests, discussions, and commit messages.
- Harassment, discriminatory language, and personal attacks are not tolerated.
- Disagreements about technical choices are welcome; disagreements about someone's identity or existence are not.

## Enforcement

Report violations privately to the repository maintainer through GitHub's contact mechanism or by the email listed in the Git commit history. Reports will be handled confidentially.

Consequences for violations range from a private warning to a permanent ban from project spaces, depending on severity. The maintainer's decision is final.

The full Contributor Covenant text — including the complete enforcement ladder — is available at https://www.contributor-covenant.org/version/2/1/code_of_conduct/.
